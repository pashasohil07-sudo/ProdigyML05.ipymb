# 🍔 Food Recognition & Calorie Estimation

## 📌 Project Overview

This project develops a **food recognition and calorie estimation model** using Python and Machine Learning. The system identifies food items from images and estimates their calorie content, helping users understand and track their dietary intake.

## 🎯 Objectives

* Recognize food items from images
* Classify different food categories
* Estimate calorie content
* Preprocess and analyze image data
* Train and evaluate machine learning models
* Display the predicted food and estimated calories

## 🛠️ Technologies Used

* Python
* NumPy
* Matplotlib
* OpenCV
* Scikit-learn
* Google Colab

## 🧠 Machine Learning Models

The project uses:

* **Random Forest Classifier** — for food recognition
* **Random Forest Regressor** — for calorie estimation

## 🔄 Project Workflow

```text
Food Image
    ↓
Image Preprocessing
    ↓
Feature Extraction
    ↓
Food Classification
    ↓
Calorie Estimation
    ↓
Display Result
```

## 🍎 Food Categories

The demonstration includes:

* 🍎 Apple
* 🍌 Banana
* 🍕 Pizza
* 🍔 Burger
* 🍚 Rice

## 📊 Output

Example:

```text
Predicted Food: Pizza
Estimated Calories: 285 kcal
```

The model performance is evaluated using:

* Accuracy
* Mean Absolute Error (MAE)

## 🚀 How to Run

1. Open the notebook in **Google Colab**.
2. Import the required Python libraries.
3. Generate or load the image data.
4. Preprocess the images.
5. Train the food classification model.
6. Train the calorie estimation model.
7. Test the models.
8. Display the predicted food and estimated calories.
